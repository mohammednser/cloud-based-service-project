# دليل توثيق الوظائف البرمجية للمشروع

## 1. وظيفة رفع الملفات (Upload)
- **الوصف:** رفع ملفات PDF/Word إلى التخزين السحابي (S3) مع استخراج النص والعنوان وتصنيف المستند تلقائيًا.
- **الكود:**
  - رفع الملف يتم عبر uploadData من aws-amplify/storage.
  - استخراج النص والعنوان عبر extractPdfTitleAndText أو extractDocxTitleAndText.
  - التصنيف الذكي عبر classifyWithNlpCloud (إذا توفر API) أو classifyDocument (خوارزمية محلية).
  - بعد الرفع، يتم إنشاء سجل في قاعدة البيانات عبر GraphQL mutation (createDocument) باستخدام client.graphql.
- **الربط السحابي:** التخزين S3 + قاعدة بيانات DynamoDB (عبر AppSync GraphQL API).
- **الخوارزمية:**
  1. رفع الملف إلى S3.
  2. استخراج النص والعنوان.
  3. تصنيف المستند.
  4. إنشاء سجل في قاعدة البيانات.

## 2. وظيفة البحث (Search)
- **الوصف:** البحث عن المستندات في قاعدة البيانات السحابية باستخدام GraphQL API.
- **الكود:**
  - استخدام client.graphql مع الاستعلام searchDocuments وتمرير متغير filter.
  - عرض النتائج مع دعم التحميل المتدرج (Skeleton UI).
- **الربط السحابي:** AppSync GraphQL API.
- **الخوارزمية:**
  1. استقبال مصطلح البحث.
  2. تنفيذ استعلام GraphQL مع المتغير.
  3. عرض النتائج أو رسالة عدم وجود نتائج.

## 3. وظيفة التصنيف (Classify)
- **الوصف:** تصنيف المستندات تلقائيًا بناءً على النص أو العنوان.
- **الكود:**
  - classifyWithNlpCloud: استدعاء API خارجي (NLP Cloud) إذا توفر مفتاح API.
  - classifyDocument: خوارزمية محلية تعتمد على الكلمات المفتاحية.
- **الربط السحابي:** (اختياري) خدمة NLP Cloud أو التصنيف المحلي.
- **الخوارزمية:**
  1. إذا توفر API خارجي استخدمه.
  2. وإلا استخدم التصنيف المحلي.

## 4. وظيفة الفرز (Sort)
- **الوصف:** فرز المستندات حسب العنوان أو التصنيف أو الحجم.
- **الكود:**
  - جلب المستندات عبر client.graphql مع استعلام listDocuments.
  - فرز النتائج محليًا حسب الحقل والاتجاه.
- **الربط السحابي:** AppSync GraphQL API.
- **الخوارزمية:**
  1. جلب جميع المستندات.
  2. فرز النتائج محليًا.

## 5. وظيفة الإحصائيات (Stats)
- **الوصف:** عرض إحصائيات المستندات (عدد، حجم، متوسط، توزيع التصنيفات).
- **الكود:**
  - جلب جميع المستندات عبر client.graphql مع استعلام listDocuments.
  - حساب الإحصائيات محليًا.
  - عرض رسم بياني دائري للتوزيع.
- **الربط السحابي:** AppSync GraphQL API.
- **الخوارزمية:**
  1. جلب جميع المستندات.
  2. حساب الإحصائيات.
  3. عرض النتائج.

# نصائح تقنية لتحسين المشروع
- استخدم متغيرات بيئة آمنة (env) لحماية مفاتيح API.
- فعل التحقق من صحة الملفات قبل الرفع (الحجم، النوع).
- أضف معالجة أخطاء متقدمة (رسائل واضحة للمستخدم).
- حسّن تجربة المستخدم عبر Skeleton UI وloading indicators.
- استخدم Lazy Loading للملفات الكبيرة أو النتائج الكثيرة.
- أضف دعم الترجمة الكاملة (i18n) لكل النصوص.
- راجع صلاحيات التخزين والـ CORS في إعدادات AWS S3 وAppSync.
- احرص على تحديث التبعيات بشكل دوري.
- أضف اختبارات تلقائية (unit/integration) للوظائف الحرجة.
- راقب الأداء عبر أدوات مثل Lighthouse وReact Profiler.

# خطوات النشر على Netlify
1. اربط المشروع مع GitHub.
2. أضف ملف netlify.toml وpublic/_redirects.
3. حدد أمر البناء: npm run build.
4. حدد مجلد النشر: build
5. أضف متغيرات البيئة (API URLs, مفاتيح).
6. اختبر الموقع بعد النشر وتأكد من عمل جميع الوظائف.
